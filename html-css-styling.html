CSS Display Property Examples

1. display: block

Block 1
Block 2

block elements start on new line and fill available width. Default for <div>, <p>, <h1>-<h6>.

2. display: inline

Inline 1
Inline 2
Inline 3
Notice how inline elements flow within text content like this. They don't accept width/height properties.

inline elements flow within text. Default for <span>, <a>, <strong>. Width/height have no effect.

3. display: inline-block

Inline-Block 1
Inline-Block 2
Inline-Block 3

inline-block flows like inline but accepts width/height like block. Perfect for horizontal menus.

4. display: none

Box 1 (visible)

none completely removes element from layout (not just invisible). The orange box doesn't take up any space.

5. display: flex

Flex Item 1

flex creates flexible box layout. Container controls child alignment, order, and sizing.
