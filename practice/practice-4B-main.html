BIO

The CSS justify-content property controls the alignment of items along the main axis of a flex or grid container. It distributes any remaining free space between and around items, using values such as flex-start, center, space-between, space-around, and space-evenly. The specific direction of the main axis is determined by the flex-direction property (horizontal for row, vertical for column).
